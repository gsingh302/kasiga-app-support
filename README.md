# App Store Support Site

Publish the contents of this directory unchanged at the root of a stable public HTTPS website. Static hosts such as GitHub Pages, Cloudflare Pages, Netlify, or an existing company website are sufficient.

After deployment, use these URLs in App Store Connect, replacing the host with the real public domain:

- Support URL for all three apps: `https://YOUR-PUBLIC-DOMAIN.example/support.html`
- Kinetic Halo privacy: `https://YOUR-PUBLIC-DOMAIN.example/privacy/kinetic-halo.html`
- Chroma Surge privacy: `https://YOUR-PUBLIC-DOMAIN.example/privacy/chroma-surge.html`
- Nova Chain privacy: `https://YOUR-PUBLIC-DOMAIN.example/privacy/nova-chain.html`

Open every final URL in a private browser window before submission. The pages must remain reachable without a login.
